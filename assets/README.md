# Custom card art

Drop PNG files here to replace the built-in illustrations. Any file that is
missing simply falls back to the built-in SVG art, so you can replace cards one
at a time. Images fill the whole card (5:7 ratio, e.g. 500×700), so card fronts
should include their own number / ↻ / REM markings.

| File | Card |
| --- | --- |
| `back_dream.png`, `back_nightmare.png`, `back_rem.png` | Card backs |
| `dream_1.png` … `dream_6.png`, `dream_jolly.png` | Dream fronts |
| `nightmare_1.png` … `nightmare_6.png`, `nightmare_jolly.png` | Nightmare fronts |
| `rem.png` | REM front |
